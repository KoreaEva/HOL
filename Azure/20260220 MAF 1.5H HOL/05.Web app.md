## **Chapter 5. 실전! MVPTour 웹 서비스 단계별 빌드업**

### **Step 1: 기본 채팅 인터페이스 만들기**
![image](https://github.com/KoreaEva/HOL/blob/master/Azure/20260220%20MAF%201.5H%20HOL/images/05-001.png?raw=true)<br>

가장 먼저 Streamlit의 기본 틀과 에이전트의 '인사' 기능만 구현해 봅니다.

```python
import streamlit as st
import asyncio
import os
from dotenv import load_dotenv
from azure.identity import AzureCliCredential
from agent_framework.azure import AzureOpenAIResponsesClient

# 환경 변수 로드
load_dotenv()

st.set_page_config(page_title="MVPTour", page_icon="✈️")
st.title("✈️ MVPTour 상담 데스크")

# 에이전트 초기화 (세션 상태 활용)
if "agent" not in st.session_state:
    client = AzureOpenAIResponsesClient(
        credential=AzureCliCredential(),
        deployment_name=os.getenv("AZURE_OPENAI_CHAT_DEPLOYMENT"),
        project_endpoint=os.getenv("AZURE_AI_PROJECT_ENDPOINT")
    )
    st.session_state.agent = client.as_agent(
        instructions="당신은 MVPTour 상담원입니다. 끝에는 '즐거운 여행의 시작, MVPTour입니다!'를 붙이세요.",
        name="MVPTour-Assistant"
    )

# 채팅 입력창
if prompt := st.chat_input("안녕하세요! 무엇을 도와드릴까요?"):
    with st.chat_message("user"):
        st.markdown(prompt)

    with st.chat_message("assistant"):
        # 에이전트 실행
        response = asyncio.run(st.session_state.agent.run(prompt))
        st.markdown(response)

```

> **✅ 결과 확인:** `streamlit run app.py`를 실행하면 기본적인 채팅이 가능해집니다. 하지만 아직 날씨나 환율은 모르는 상태입니다.

### **Step 2: 날씨 & 환율 도구(Tools) 장착하기**

이제 위 코드에 **도구(Tools)** 기능을 추가하여 에이전트에게 실시간 정보를 조회하는 능력을 줍니다.

**[수정 부분]** 에이전트 생성 코드 위에 도구 함수를 정의하고 `tools` 인자를 추가합니다.

```python
from agent_framework import tool
from typing import Annotated
from pydantic import Field
from random import randint

# --- [추가] 도구 정의 ---
@tool(approval_mode="never_require")
def get_weather(location: Annotated[str, Field(description="지역")]) -> str:
    """날씨 정보를 가져옵니다."""
    return f"{location}은 현재 맑음, 기온은 {randint(15, 25)}°C입니다."

# --- [수정] 에이전트 생성 부분 ---
st.session_state.agent = client.as_agent(
    instructions="...상동...",
    name="MVPTour-Assistant",
    tools=[get_weather] # 도구 추가!
)

```

> **💡 Tip:** 이제 "시애틀 날씨 알려줘"라고 물어보면 에이전트가 함수를 호출하여 답변합니다.

### **Step 3: 사내 지식(RAG) 검색 능력 추가하기**

회사 내부 규정(환불 정책 등)을 답변할 수 있도록 **ChromaDB**와 **검색 도구**를 추가합니다.

**[수정 부분]** 코드 상단에 DB 초기화 로직을 넣고, 검색 도구를 추가합니다.

```python
import chromadb

# --- [추가] 지식 베이스 초기화 ---
if "collection" not in st.session_state:
    chroma_client = chromadb.Client()
    col = chroma_client.get_or_create_collection(name="tour_info")
    col.add(
        documents=["취소 규정: 7일 전 100% 환불, 이후 50% 수수료 발생"],
        ids=["doc1"]
    )
    st.session_state.collection = col

# --- [추가] 검색 도구 정의 ---
@tool(approval_mode="never_require")
def search_docs(query: Annotated[str, Field(description="검색어")]) -> str:
    """사내 지식을 검색합니다."""
    res = st.session_state.collection.query(query_texts=[query], n_results=1)
    return f"검색 결과: {res['documents'][0][0]}"

# --- [수정] 에이전트에 도구 추가 ---
tools=[get_weather, search_docs] 

```

### **Step 4: 대화 기록 유지하기 (최종 완성)**

현재 앱은 질문을 던질 때마다 이전 대화 내용을 잊어버립니다. `st.session_state.messages`와 에이전트의 `session`을 사용해 대화 흐름을 유지하게 만듭니다.

**[최종 수정]** 채팅 표시 부분에 기록 저장 로직을 넣습니다.

```python
# --- [추가] 메시지 기록 초기화 ---
if "messages" not in st.session_state:
    st.session_state.messages = []
    st.session_state.chat_session = st.session_state.agent.create_session()

# --- [수정] 대화 표시 루프 ---
for msg in st.session_state.messages:
    with st.chat_message(msg["role"]):
        st.markdown(msg["content"])

if prompt := st.chat_input("질문하세요!"):
    st.session_state.messages.append({"role": "user", "content": prompt})
    # ... (중략) ...
    # 에이전트 실행 시 session 인자 전달
    response = asyncio.run(st.session_state.agent.run(prompt, session=st.session_state.chat_session))
    
    st.session_state.messages.append({"role": "assistant", "content": response})

```

### **💡 핸즈온 요약**

1. **Step 1:** Streamlit의 `chat_input`과 에이전트의 `run`을 연결해 껍데기를 만들었습니다.
2. **Step 2:** `@tool`을 통해 외부 API(가상 날씨) 호출 능력을 더했습니다.
3. **Step 3:** `ChromaDB`를 연동해 에이전트가 모르는 사내 정보를 찾게 했습니다.
4. **Step 4:** `session_state`로 사용자와의 대화 맥락(Context)을 기억하게 완성했습니다.
