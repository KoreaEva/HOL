## **Chapter 2. Azure AI Agent SDK로 만드는 MVPTour 상담원**

본 장에서는 **Azure AI Agent SDK**를 사용하여 여행사 상담원 역할을 수행하는 AI 에이전트를 구축합니다. 이 프레임워크는 복잡한 Thread 관리나 Run 생성을 내부적으로 처리해주어, 개발자가 에이전트의 **'페르소나(Persona)'**와 **'비즈니스 로직'**에만 집중할 수 있게 도와줍니다.

보안과 유지보수를 위해 설정 정보를 `.env` 파일에 저장합니다. 프로젝트 루트 폴더에 파일을 만들고 프로젝트 엔드포인트와 모델 배포명을 입력하세요.

### **3. 단계별 코드 작성**

`02_mvp_agent_simple.py` 파일을 생성하고 아래 순서대로 코드를 작성하며 각 단계의 의미를 파악해 봅니다.

#### **Step 1: 환경 변수 로드 및 인증 설정**

가장 먼저 환경 변수를 불러오고, Azure 서비스에 안전하게 접근하기 위한 `AzureCliCredential`을 설정합니다.

```python
import asyncio
import os
from dotenv import load_dotenv
from azure.identity import AzureCliCredential
from agent_framework.azure import AzureOpenAIResponsesClient

# 1. .env 파일로부터 환경 변수 로드
load_dotenv()
deployment_name = os.getenv("AZURE_OPENAI_CHAT_DEPLOYMENT")
project_endpoint = os.getenv("AZURE_AI_PROJECT_ENDPOINT")

# 2. Azure CLI를 통한 인증 (로컬 개발 시 편리)
credential = AzureCliCredential()

```

#### **Step 2: 클라이언트 초기화 및 에이전트 정의**

에이전트에게 이름과 구체적인 지침(Instructions)을 부여하여 '상담원'이라는 정체성을 설정합니다.

```python
# 3. 클라이언트 설정
client = AzureOpenAIResponsesClient(
    credential=credential,
    deployment_name=deployment_name,
    project_endpoint=project_endpoint
)

# 4. MVPTour 상담원(Agent) 생성
# as_agent 메서드는 지침과 이름을 가진 에이전트 객체를 반환합니다.
agent = client.as_agent(
    instructions="""
    당신은 여행사 'MVPTour'의 상담원입니다. 
    고객에게 정중하게 인사하고, 여행 계획에 대해 도움을 줄 준비가 되었음을 알리세요.
    답변 끝에는 항상 '즐거운 여행의 시작, MVPTour입니다!'라는 문구를 붙여주세요.
    """,
    name="MVPTour-Assistant"
)

```

#### **Step 3: 비동기 실행 함수 작성**

에이전트와의 대화는 비동기(`async`) 방식으로 이루어집니다. 사용자 입력을 전달하고 답변을 기다리는 과정을 구현합니다.

```python
async def main():
    print(f"✅ 에이전트 '{agent.name}'가 준비되었습니다.")

    # 5. 사용자 입력 구성
    user_input = "안녕하세요! 도쿄 여행 패키지 추천해 주세요."
    print(f"\n[나]: {user_input}")
    
    # 6. 에이전트 실행 (Non-streaming 방식)
    # 별도의 스레드 생성 단계 없이 agent.run()으로 즉시 답변을 받아옵니다.
    result = await agent.run(user_input)
    
    print(f"\n[MVPTour 상담원]: {result}")

if __name__ == "__main__":
    asyncio.run(main())

```

---

### **💡 핵심 포인트 정리**

1. **AzureCliCredential:** 별도의 API Key 없이 Azure CLI에 로그인된 계정 권한을 사용하여 보안상 더 안전합니다.
2. **as_agent:** 에이전트의 성격(Persona)을 정의하는 핵심 함수입니다. `instructions`를 통해 답변의 어조와 필수 문구를 제어할 수 있습니다.
3. **High-level Abstraction:** 기존 방식은 Thread 생성 -> Message 생성 -> Run 생성의 복잡한 단계를 거치지만, 이 프레임워크는 `agent.run()` 한 줄로 이 모든 과정을 처리합니다.
4. **Async/Await:** 네트워크 대기 시간 동안 프로그램이 멈추지 않도록 비동기 처리를 기본으로 사용합니다.
