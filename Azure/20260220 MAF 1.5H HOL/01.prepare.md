# ✈️ MVPTour 에이전트 핸즈온랩 교육안

## **준비. 환경 구축 및 실습 준비 (Preparations)**


---

본 장에서는 90분간의 실습이 원활하게 진행될 수 있도록 클라우드 개발 환경인 **GitHub Codespaces**를 설정하고, **Azure OpenAI** 리소스를 연결하며, **RAG(검색 증강 생성)**를 위한 기초 데이터를 준비합니다.

---

### **1. 실습 환경: GitHub Codespaces 설정**

로컬 PC의 사양이나 OS에 상관없이 동일한 환경에서 실습하기 위해 GitHub의 클라우드 IDE를 사용합니다.

* **저장소 복사(Fork):** 강사가 제공한 `MVPTour` 베이스 저장소를 본인의 계정으로 Fork 합니다.
* **Codespace 생성:** 1.  Fork한 본인의 저장소에서 `Code` 버튼(초록색)을 클릭합니다.
2.  `Codespaces` 탭을 선택하고 `Create codespace on main`을 클릭합니다.
3.  브라우저 내에 VS Code 환경이 실행될 때까지 약 1~2분 기다립니다.
* **터미널 확인:** VS Code 하단 터미널에서 `python --version`을 입력하여 Python 3.10 이상인지 확인합니다.

---

### **2. 필수 라이브러리 설치 (`requirements.txt`)**

복사 붙여넣기 방식으로 아래 명령어를 터미널에 입력하여 실습에 필요한 핵심 패키지들을 설치합니다.

```bash
# 터미널에 입력
pip install agent-framework -pre
```

**[라이브러리 역할 설명]**

* **`pyautogen`**: Microsoft Agent Framework의 핵심으로, 멀티 에이전트 간의 대화를 관리합니다.
* **`chromadb`**: 별도의 서버 설치 없이 사용할 수 있는 초경량 VectorDB로, RAG 구현에 사용됩니다.
* **`streamlit`**: 작성한 파이썬 코드를 즉시 웹 서비스 형태(UI)로 변환해 줍니다.
* **`python-dotenv`**: API 키와 같은 민감한 정보를 `.env` 파일에서 안전하게 관리합니다.

---

### **3. Azure OpenAI 서비스 연결 설정**

에이전트의 두뇌가 될 Azure OpenAI의 API 정보를 연동합니다. 저장소 루트 디렉토리에 `.env` 파일을 만들고 아래 내용을 복사한 뒤, 본인의 정보를 입력합니다.

* **파일 생성:** `New File` -> 이름: `.env`
* **내용 작성 (복사해서 사용):**

```text
# 이미지 왼쪽 'Microsoft Foundry 프로젝트 엔드포인트' 복사
AZURE_AI_PROJECT_ENDPOINT="<YOUR_PROJECT_ENDPOINT>"
AZURE_AI_PROJECT_KEY="<YOUR_API_KEY>"

AZURE_SUBSCRIPTION_ID="<YOUR SUBSCRIPTION KEY>"
AZURE_RESOURCE_GROUP="<YOUR RESOURCE_GROUP>"
AZURE_PROJECT_NAME="<YOUR_PROJECT_NAME>"

# 배포 모델명 (Azure Portal에 설정한 이름)
AZURE_OPENAI_CHAT_DEPLOYMENT="gpt-4.1-mini"

AZURE_AI_MODEL_DEPLOYMENT_NAME="gpt-4.1-mini"
#AZURE_OPENAI_CHAT_DEPLOYMENT_NAME="gpt-4.1-mini"
AZURE_OPENAI_ENDPOINT="<YOUR_OPENAI_ENDPOINT>"
```

> **⚠️ 주의:** `AZURE_OPENAI_CHAT_DEPLOYMENT`와 `AZURE_OPENAI_EMBEDDING_DEPLOYMENT`는 Azure AI Studio에서 직접 설정한 **'배포 이름'**을 정확히 입력해야 합니다. (모델명과 다를 수 있음)

---

### **4. Azure CLI의 설치**

MVPTour만의 '특가 상품' 정보를 에이전트가 학습할 수 있도록 데이터를 준비합니다.

* **파일 경로:** `data/special_deals.txt` (폴더가 없으면 생성)
* **내용 (복사해서 사용):**

```text
1. 문제가 되는 Yarn 저장소 설정 삭제

sudo rm -f /etc/apt/sources.list.d/yarn.list

2. 패키지 리스트 강제 업데이트 (이제 오류 없이 돌아갈 겁니다)

sudo apt update

3. 다시 Azure CLI 설치 스크립트 실행

curl -sL https://aka.ms/InstallAzureCLIDeb | sudo bash
```
