## Polaris Tool 활용
Polaris에서는 아래와 같은 다양한 도구를 이용해서 에이전트를 강력하게 만들 수 있다. 
![image](https://github.com/KoreaEva/HOL/blob/master/Agents/20260420%20SKT-AX%20Frontier/Part_02/images/02-01.png?raw=true)

### **1. 커뮤니케이션 및 알림 도구**
AI 에이전트가 분석한 결과나 업무 프로세스의 진행 상황을 사용자 또는 팀원에게 전달하는 도구입니다.

* **이메일 보내기**: SMTP 또는 전용 API를 통해 이메일을 발송합니다. 단순 텍스트뿐만 아니라 AI가 생성한 보고서를 첨부하거나, 특정 조건(예: 주식 급락) 충족 시 자동 알림을 보내는 워크플로우에 필수적입니다.
![image](https://github.com/KoreaEva/HOL/blob/master/Agents/20260420%20SKT-AX%20Frontier/Part_02/images/02-02.png?raw=true)

* **이메일 템플릿**: 미리 정의된 레이아웃에 AI가 생성한 변수(이름, 날짜, 분석 결과 등)를 삽입합니다. 일관된 브랜드 보이스를 유지하거나 표준화된 보고 형식을 갖출 때 사용합니다.
![image](https://github.com/KoreaEva/HOL/blob/master/Agents/20260420%20SKT-AX%20Frontier/Part_02/images/02-03.png?raw=true)


* **톡톡 메시지 [Beta]**: 네이버 톡톡과 같은 실시간 메신저 채널로 메시지를 전송합니다. 이메일보다 즉각적인 대응이 필요한 고객 응대나 내부 알림용으로 적합합니다.
![image](https://github.com/KoreaEva/HOL/blob/master/Agents/20260420%20SKT-AX%20Frontier/Part_02/images/02-06.png?raw=true)


### **2. 협업 및 지식 관리 (Atlassian Confluence 연동)**
기업 내 지식 베이스(Knowledge Base)와 에이전트를 연결하여 **RAG(검색 증강 생성)** 및 문서화 자동화를 지원합니다.

* **컨플루언스 작성 [Beta]**: AI가 회의록을 요약하거나 기술 문서를 초안한 뒤, 이를 팀의 컨플루언스 페이지에 직접 업로드합니다. 문서 작성의 번거로움을 줄여주는 '에이전트용 라이터' 기능입니다.
![image](https://github.com/KoreaEva/HOL/blob/master/Agents/20260420%20SKT-AX%20Frontier/Part_02/images/02-04.png?raw=true)


* **컨플루언스 조회 [Beta]**: 기존 컨플루언스에 저장된 방대한 사내 규정, 프로젝트 히스토리 등을 에이전트가 읽어옵니다. 이를 통해 "우리 회사 보안 규정이 뭐야?" 같은 질문에 정확히 답변할 수 있는 근거 데이터를 확보합니다.
![image](https://github.com/KoreaEva/HOL/blob/master/Agents/20260420%20SKT-AX%20Frontier/Part_02/images/02-05.png?raw=true)


### **3. 데이터 분석 및 시각화**
단순 텍스트 답변을 넘어 데이터에 기반한 인사이트를 시각적으로 제공하는 기능입니다.

* **EDA 그래프 [Beta]**: **탐색적 데이터 분석(Exploratory Data Analysis)** 기능을 수행합니다. 업로드된 데이터셋(CSV, Excel 등)의 분포나 상관관계를 에이전트가 파악하고, 이를 차트나 그래프 형태로 즉시 시각화하여 보고서의 품질을 높입니다.
![image](https://github.com/KoreaEva/HOL/blob/master/Agents/20260420%20SKT-AX%20Frontier/Part_02/images/02-07.png?raw=true)


### **4. 개발 및 시스템 확장 도구**
가장 기술적인 부분으로, Polaris.Studio가 단순 챗봇을 넘어 **'에이전트 플랫폼'**으로서의 정체성을 보여주는 구간입니다.

* **HTML 에디터 [Beta]**: 에이전트가 웹 콘텐츠를 생성하거나 수정할 때 사용합니다. 메일 본문을 HTML로 정교하게 디자인하거나, 간단한 웹 페이지 대시보드를 생성하는 용도로 활용됩니다.
![image](https://github.com/KoreaEva/HOL/blob/master/Agents/20260420%20SKT-AX%20Frontier/Part_02/images/02-08.png?raw=true)


* **MCP 클라이언트 (Model Context Protocol)**: **앤스로픽(Anthropic)**에서 제안한 표준 프로토콜로, AI 모델이 로컬 파일, DB, 외부 API 등에 안전하고 표준화된 방식으로 접근할 수 있게 합니다. 이 기능이 있다는 것은 다양한 외부 서비스와의 확장성이 매우 높음을 의미합니다.
![image](https://github.com/KoreaEva/HOL/blob/master/Agents/20260420%20SKT-AX%20Frontier/Part_02/images/02-09.png?raw=true)

* **RPA 실행하기**: **Robotic Process Automation**과 연동됩니다. API가 없는 구형 시스템(Legacy)이나 데스크톱 앱에서의 반복 작업을 수행하는 봇을 AI 에이전트가 트리거하여, 진정한 의미의 '업무 종단간 자동화(End-to-End Automation)'를 실현합니다.
![image](https://github.com/KoreaEva/HOL/blob/master/Agents/20260420%20SKT-AX%20Frontier/Part_02/images/02-10.png?raw=true)
