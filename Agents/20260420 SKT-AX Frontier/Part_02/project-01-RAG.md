# [RFP] Polaris Studio 기반 자율 주제 AI 에이전트 구축 미니 프로젝트

## 1. 프로젝트 개요
* 프로젝트 명: [자율 주제] Polaris Studio를 활용한 하이브리드 지식 기반 지능형 에이전트 구축
* 목적: 수행자가 직접 선정한 도메인의 문제를 AI 에이전트로 해결하며, 데이터 가공부터 외부 시스템 연동, 업무 자동화(이메일)까지의 전 과정을 경험함.

## 2. 핵심 요구사항 (Mandatory)
본 프로젝트는 주제 선정의 자유가 있으나, 기술적으로 아래의 5가지 요소가 반드시 포함되어야 합니다.

1.  직접 가공한 데이터 기반 RAG: 수행자가 선정한 주제에 맞춰 Excel 또는 CSV 형태로 데이터를 직접 정제하고 Polaris Studio '지식'에 학습시켜야 함.
2.  컨플루언스(Confluence) 연동: 사내 위키 또는 외부 공개 컨플루언스 페이지의 정보를 연동하여 엑셀 데이터와 상호 보완적인 답변이 가능해야 함.
3.  실시간 시간 정보 활용: 답변 시 현재 날짜와 시간을 인지하여 응답에 포함하거나, 시간을 기준으로 답변의 로직이 변해야 함.
4.  이메일 발송 스킬(Skill): 사용자의 요청 시 답변 내용을 외부로 전송할 수 있는 이메일 발송 기능이 구현되어야 함.
5.  구조화된 이메일 템플릿: 발송되는 이메일은 단순 텍스트가 아닌, 이메일 템플릿을 적용하여 가공된 형태(제목, 본문, 하단 정보 등)로 전달되어야 함.

## 3. 과업 상세 가이드

### A. 주제 및 데이터 선정 (자율)
* 수행자는 실무, 개인 비서, 특정 전문 분야 등 자유롭게 주제를 선정함.
* 데이터 A: 엑셀로 직접 가공한 정형 데이터 (예: 가격표, 연락처, 일정표 등).
* 데이터 B: 컨플루언스에 정리된 비정형 데이터 (예: 가이드라인, 기획서, 규정 등).

### B. 에이전트 지능 설계
* 현재 시간 인지: 시스템 프롬프트 또는 변수(`{{current_time}}` 등)를 활용하여 실시간성을 확보함.
* 멀티 소스 참조: 질문의 의도에 따라 엑셀과 컨플루언스 중 적절한 데이터를 찾아 답변하도록 설계함.

### C. 업무 자동화 (Action)
* 사용자가 "메일로 보내줘" 혹은 "보고서 형태로 전송해"라고 요청할 경우 스킬이 트리거되어야 함.
* 이메일 발송 시 전문적인 템플릿을 적용하여 사용자 경험을 극대화함.

## 4. 최종 결과물 (Deliverables)
1.  수행 계획서: 선정한 주제 및 데이터 소스 정의.
2.  정제 데이터셋: 직접 가공한 엑셀 파일.
3.  완성형 에이전트: Polaris Studio 내에서 모든 기능이 작동하는 에이전트.
4.  이메일 결과물: 실제 발송된 템플릿 적용 메일 스크린샷 또는 샘플.

## 5. 평가 항목
* 주제 적합성: 선정한 주제가 AI 에이전트를 활용하기에 적절하며 실무적 가치가 있는가?
* 기술 통합력: RAG(Excel+Confluence), 시간 인지, 이메일 스킬이 유기적으로 작동하는가?
* 데이터 가공 숙련도: 엑셀 데이터가 AI가 이해하기 좋게 논리적으로 잘 정리되었는가?
* 이메일 퀄리티: 제공된 이메일 템플릿이 전문적이고 가독성이 높은가?
