## [EPISODE 6] "데이터는 흐른다, MCP라는 강물을 타고"

### 1. 지옥에서 온 엑셀(Excel) 뭉치, 그리고 에이전트의 배신

![image](https://github.com/KoreaEva/HOL/blob/master/Agents/20260420%20SKT-AX%20Frontier/Part_02/images/lab03-01.png?raw=true)

AX 집중 교육을 마치고 금의환향한 김영웅 사원이 복귀하기 직전, 박 부장님이 또 일을 던졌습니다.
"한 과장, 여기 전국 대리점별 요금제 가입 현황 Excel 파일 50개랑 CSV 파일 30개 있거든? 이거 다 합쳐서 분석 데이터 세트 하나 만들어봐. 아, 오늘 퇴근 전까지!"

송희 과장은 Polaris Studio를 켜고 에이전트에게 파일을 통째로 던졌습니다.
> 송희 과장: "이 파일들 다 읽어서 중복 제거하고, CSV 하나로 합쳐줘."

...하지만, 모니터에는 황당한 대답이 떴습니다.
> 에이전트: "죄송합니다. 80개 파일의 포맷(날짜 형식, 컬럼명 등)이 서로 달라 합칠 수 없습니다. 데이터를 먼저 정리해 주세요."

송희 과장의 머릿속이 하얗게 변했습니다. "아니, 내가 정리를 못 해서 너한테 던진 거잖아! 이럴 거면 AI를 왜 써!"

### 2. 구원자 박나례 대리의 재등장: "데이터 관리에 데이터를 먼저 올리셔야 되요"

![image](https://github.com/KoreaEva/HOL/blob/master/Agents/20260420%20SKT-AX%20Frontier/Part_02/images/lab03-02.png?raw=true)

송희 과장이 머리를 쥐어뜯고 있을 때, 옆자리 박나례 대리가 슬며시 고개를 내밀었습니다.
"언니, 또 손으로 엑셀 합치려고요? 에이전트한테 그냥 던지면 안 돼요. 에이전트가 데이터를 잘 먹으려면 '전처리(Preprocessing)' 과정이 필요하다고요."

나례 대리는 송희 과장의 마우스를 뺏어 들고 Polaris Studio의 [데이터 관리] 메뉴을 열었습니다.

"에이전트에게 파일을 직접 던지는 게 아니라, 이 '데이터 관리'에 등록해야 해요. 여기서 엑셀데이터는 클로드를 이용한 분석 기능을 사용해야 해요. 그럼 알아서 날짜 형식도 맞추고 컬럼명도 통일해서 '표준 데이터 세트'로 만들어 준다고요."

나례 대리의 손길 몇 번에 80개의 난잡한 파일이 하나의 깨끗한 표준 데이터 세트로 정리되었습니다. 송희 과장의 입이 떡 벌어졌습니다. CSV 파일은 이거보다 조금 더 강력하게 처리 할 수 있어요.

### 3. "너도 써봐!" 데이터세트 공유의 맛
만들어진 데이터 세트가 너무 훌륭하자, 송희 과장은 옆 팀 이 과장이 슬쩍 다가옵니다.
"한 과장, 그 정리된 데이터 나도 좀 쓸 수 있을까? 메일로 보내주면 우리 팀 에이전트한테도 그 데이터를 넣을 수 있을 것 같은데.."

송희 과장은 데이터를 어떻게 공유할까 고민하고 있었는데 Polaris Studio의 [데이터세트 공유] 항목이 눈에 들어왔다.

"이 과장님, 메일로 보내드릴 필요 없어요. 생성한 이 데이터를 공유해 드릴께요.

이제 팀원들은 각자의 에이전트를 쓰지만, 송희 과장이 만든 '정답 데이터'를 실시간으로 공유하며 협업하게 되었습니다.

### 4. 나철벽의 최종 훈수: "이제는 MCP Client 시대입니다"

![image](https://github.com/KoreaEva/HOL/blob/master/Agents/20260420%20SKT-AX%20Frontier/Part_02/images/lab03-03.png?raw=true)

데이터 공유까지 성공하며 하나하나 문제를 해결해 가던 송희 과장. 하지만 그녀는 에이전트의 대답을 일일이 복사해서 사용하는 것이 슬슬 귀찮아지고 있었다. 이때 또 나철벽 대리가 선글라스를 고쳐 쓰며 나타납니다.

"한 과장님, 아직도 복사-붙여넣기 하십니까? 에이전트를 브라우저 안에만 가둬두지 마세요. 이제 MCP Client를 써야 할 때입니다."
