검색 증강 생성(RAG)은 관련 콘텐츠에 대한 임베딩을 벡터 데이터베이스에 미리 로드하여 거대 언어 모델(LLM)에 추가적인 컨텍스트를 제공하는 방법입니다. 사용자가 LLM과 채팅할 때, *유사도 검색*을 통해 사용자의 쿼리 임베딩과 벡터 데이터베이스의 임베딩을 비교하여 관련 콘텐츠를 가져옵니다. 예를 들어, 제품 데이터를 RAG 챗봇에 미리 로드해두면 고객이 질문을 통해 특정 제품을 찾도록 도울 수 있습니다. 이 템플릿은 두 개의 서브 플로우로 구성됩니다. 하나는 벡터 저장소에 데이터를 로드하는 플로우이며, 다른 하나는 사용자의 새로운 쿼리를 벡터 데이터베이스의 기존 콘텐츠와 비교하는 채팅 플로우입니다.

## **플로우 실행**

1.  📚 **Load Data** 플로우를 사용하여 데이터를 벡터 데이터베이스에 로드하세요. **File** 컴포넌트에서 업로드할 파일을 선택한 다음, **Astra DB** 컴포넌트에서 **Play** ▶️ 버튼을 클릭하여 **Load Data** 플로우를 실행합니다.
2.  **Playground**를 열어 🐕 **Retriever** 플로우와 채팅을 시작하세요.

제품 데이터와 같은 기초 콘텐츠로 벡터 데이터베이스를 채워야 할 때만 **Load Data** 플로우를 실행하세요. **Retriever** 플로우는 사용자용 채팅 플로우입니다. 이 플로우는 채팅 입력으로부터 임베딩을 생성하고, 벡터 데이터베이스에 대한 유사도 검색을 수행하여 관련 콘텐츠를 검색한 뒤, 원래의 쿼리와 검색된 콘텐츠를 LLM으로 전달합니다. LLM은 이를 바탕으로 사용자에게 보낼 채팅 응답을 생성합니다.
